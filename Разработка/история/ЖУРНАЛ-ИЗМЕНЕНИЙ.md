# Журнал изменений Airfoil Studio

Файл заполняется **автоматически**: `инструменты\watch-history.ps1` следит за папкой
программы и дописывает сюда каждую правку. Руками править можно — скрипт только
дописывает новые записи снизу.

Как это работает, как включить/выключить и что делать при переносе —
`ЧИТАТЬ_ПЕРВЫМ.md`, раздел «История обновляется сама».

- `программа\XP\AirfoilStudio-XP.html` — XP-сборка (Firefox 52)
- `программа\airfoil-base.js` — единая файл-база профилей для обеих версий
- `история\снимки\index-2026-11-11.html` — снимок программы на эту дату
- `история\Переписка-по-проекту.md`, `история\Авто-сводки-состояния.md` — история работы
- с этого момента изменения подхватываются автоматически
