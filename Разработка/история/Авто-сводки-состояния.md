## Decisions
- XP-версия — отдельный файл `XP\AirfoilStudio-XP.html`, собранный из `index.html` транспиляцией (Babel preset-env, target Firefox 52) + compat-CSS + полифилл flex-gap; `index.html` не ломается.
- Целевой браузер XP — Firefox 52.9.0esr; установщик лежит в папке `XP`.
- Полифилл flex-gap: feature-detect, разбор `gap` из stylesheet и inline `style`, marginRight/marginBottom по flexDirection; в современных браузерах отключается; MutationObserver для новых узлов.
- Compat-CSS для FF52: `.grid2,.grid3,.grid4{grid-gap:7px}`; шрифт `Tahoma,"Segoe UI",sans-serif`; canvas-шрифты `Npx Segoe UI` → `Npx Arial`.
- В XP-сборке `await f.text()` заменён на `_blobText(f)` (FileReader) — в FF52 нет `Blob.text()`.
- **Единая база**: `airfoil-base.js` в корне папки программы — единственный источник для обеих версий. Основная программа читает его синхронным `<script src="./airfoil-base.js">`; XP-версия — асинхронным загрузчиком-цепочкой `../airfoil-base.js` → fallback `./airfoil-base.js` (только если скопирована одна папка XP), с `onerror`-переходом и hook-ом `window.fileBaseLateLoad`.
- Cache-buster в XP-загрузчике только для http(s) (`?t=Date.now()`); на `file://` кэш не мешает.
- Слияние из файла: `mergeFileBase()` добавляет отсутствующие по имени профили (с `chord`, `src`), занятые имена и битые записи пропускает; ничего не удаляет и не перезаписывает.
- Автозапись файла-базы: Chrome/Edge — File System Access API (`showSaveFilePicker` + `createWritable`), хэндл в IndexedDB (`airfoilStudio` / store `kv`, ключ `baseHandle`), `writeFileBaseSoon()` пишет через 700 мс, `restoreBaseHandle()` при старте, `armBasePermissionRequest()` на первом pointerdown/keydown.
- XP/Firefox 52: только скачивание файла → переложить в **корень** программы (рядом с `index.html`), инструкция в TXT.
- Y лонжерона: строка-расчёт `#sparYInfo` под полями X/Y («обвод ± отступ ± ½высоты» для 2 прямоугольников; центр + грани для трубы/прямоугольника).
