# Сборка версии для Windows XP

XP-версия — не отдельный проект, а **производный файл** из основного `index.html`.
Правим только `index.html`, потом пересобираем.

```
программа\index.html
        │  Babel (target: firefox 52) + слой совместимости
        ▼
программа\XP\AirfoilStudio-XP.html
```

---

## 1. Пересборка (одна команда)

Двойной щелчок: `инструменты\пересобрать-XP.bat`

или в консоли:

```
powershell -ExecutionPolicy Bypass -File инструменты\build_xp.ps1
```

Скрипт делает по порядку:

1. `extract_js.py` — вытаскивает главный `<script>` из `index.html` во временный файл;
2. `node --check` — проверка синтаксиса; **если ошибка, сборка отменяется**
   и старый XP-файл остаётся нетронутым;
3. `build_xp.js` — собирает `программа\XP\AirfoilStudio-XP.html`;
4. копирует `airfoil-base.js` в `программа\XP\` (запасная копия файл-базы).

В конце печатается JSON. Проверять так:

```json
{ "srcScript": 540000, "es5": 690000, "htmlIn": 644000, "htmlOut": 684000,
  "gridGapAdded": true, "blobTextPatched": true, "fontPatched": true }
```

* три последних значения должны быть `true`;
* если в выводе есть `WARN: loader tag not found` — в `index.html` пропал
  тег `<script src="./airfoil-base.js"></script>`, XP-версия останется без файл-базы.

Требования: **Node.js 18+** и **Python 3**. Зависимости Babel уже лежат
в `инструменты\node_modules` — интернет не нужен, `npm install` не обязателен.
Если папку `node_modules` потеряли:

```
cd инструменты
npm install
```

(нужны `@babel/core`, `@babel/preset-env` — см. `package.json`).

## 2. Что именно делает сборщик (`build_xp.js`)

| Шаг | Зачем |
|---|---|
| Находит **внутренний** `<script>` (пропускает `src=`) | не спутать с тегом файл-базы |
| Вставляет `_blobText()` и меняет `await f.text()` → `await _blobText(f)` | в Firefox 52 нет `Blob.text()`, работает `FileReader` |
| `@babel/preset-env`, `targets: { firefox: "52" }` | ES5: стрелки, классы, `async/await`, шаблоны |
| `Npx Segoe UI` → `Npx Arial` в canvas-шрифтах | на XP нет Segoe UI |
| Шрифт страницы → `Tahoma, "Segoe UI", sans-serif` | то же |
| `.grid2,.grid3,.grid4{ grid-gap:7px }` | в FF52 у Grid старое имя свойства |
| Полифилл flex-gap (`GAP_POLY`) | у flex в FF52 нет `gap` — расставляет `marginRight`/`marginBottom` |
| Замена тега базы на XP-загрузчик (`XP_LOADER`) | общий файл из `../`, иначе запасной из `./` |

Полифилл gap сам определяет, нужен ли он: в современном браузере проверка
проходит — полифилл выключается. На FF52 расставляет отступы и следит за
новыми узлами через `MutationObserver`.

## 3. Как проверить результат

**На современном компьютере:** открыть `программа\XP\AirfoilStudio-XP.html`
в Chrome/Edge/Firefox — должен работать так же, как основная версия
(это быстрая проверка «ничего не сломалось»).

**На реальном Windows XP:**

1. Установить `программа\XP\Firefox-52.9.0esr-Setup.exe` (единственный браузер,
   который там нормально работает с этой программой).
2. Открыть `программа\XP\AirfoilStudio-XP.html`.
3. Проверить: 5 вкладок переключаются, профили видны, сетка рисуется,
   G-код генерируется, консоль (Ctrl+Shift+J) без красных ошибок.

Инструкция для человека, который просто пользуется программой на XP, лежит
рядом с файлом: `программа\XP\Как запустить на Windows XP.txt`.

## 4. Ограничения XP-версии (это нормально)

| Что | Почему | Как жить |
|---|---|---|
| Нет автозаписи файл-базы | в FF52 нет File System Access API | кнопка «База — в файл» → скачанный файл переложить в корень программы |
| Нет части новых API | FF52 старый | в коде есть обходы (`_blobText`, полифилл gap) |
| Медленнее на больших профилях | старый JS-движок | шаг контура можно увеличить |

**Чего делать нельзя:** править `AirfoilStudio-XP.html` руками — при следующей
пересборке правки исчезнут. Все изменения — только в `index.html`
(или в `build_xp.js`, если нужен новый слой совместимости).

---

## 5. Если понадобится поддержать совсем другой браузер

Цель задаётся в одном месте — `build_xp.js`:

```js
presets: [[require("@babel/preset-env"), { targets: { firefox: "52" } }]]
```

Например, для Chrome 49 — `{ chrome: "49" }`. После смены цели проверить
сборку на реальном браузере: Babel синтаксис приведёт, но встроенные API
(canvas, File API) могут отличаться — тогда нужен ещё один полифилл
по образцу `_blobText` / `GAP_POLY`.
