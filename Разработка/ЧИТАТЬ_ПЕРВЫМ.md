# Airfoil Studio — папка разработки

Здесь лежит **всё, из чего сделана программа**, вся её история и инструменты,
чтобы папку можно было перенести на любой компьютер (флешка, другой ПК,
Windows XP) и спокойно продолжать разработку.

Программа — это **один HTML-файл без сборки и без интернета**: открыл двойным
щелчком — работает. Никаких установок, серверов и библиотек ей не нужно.

---

## Что внутри

Рядом с этой папкой, внутри `AirfoilStudio\`, лежит готовый архив
`AirfoilStudio-Разработка.zip` (45 МБ) — то же самое одним файлом, если удобнее
перекинуть по сети или на флешку. Распаковали — и папка `Разработка` на месте,
ничего не настраивать не нужно. Этот zip **обновляется сам**, когда меняется
программа (см. «История обновляется сама»).


```
Разработка\
├─ ЧИТАТЬ_ПЕРВЫМ.md      ← этот файл: как всё устроено и с чего начать
├─ ИСТОРИЯ.md            ← вся история создания: этапы, решения, ошибки и почему так
├─ АРХИТЕКТУРА.md        ← карта кода: что в каком месте index.html, форматы данных
├─ БАЗА_ПРОФИЛЕЙ.md      ← как хранится база, как она переносится, файл airfoil-base.js
├─ СБОРКА_XP.md          ← как из index.html делается версия для Windows XP
│
├─ программа\            ← сама программа (снимок на момент создания архива)
│   ├─ index.html        ← основная версия (Chrome / Edge / Firefox, Windows 7+)
│   ├─ airfoil-base.js   ← общая файл-база профилей (переносится вместе с программой)
│   └─ XP\
│       ├─ AirfoilStudio-XP.html          ← сборка для Windows XP (Firefox 52)
│       ├─ airfoil-base.js                ← запасная копия файл-базы для XP
│       ├─ Firefox-52.9.0esr-Setup.exe    ← браузер для XP (последний, что там работает)
│       └─ Как запустить на Windows XP.txt ← инструкция для XP (для человека)
│
├─ инструменты\          ← пересборка XP-версии, проверки, автоистория
│   ├─ build_xp.js       ← сборщик: ES5 + совместимость Firefox 52 + полифилл flex-gap
│   ├─ extract_js.py     ← достаёт скрипт программы из index.html (перед проверкой)
│   ├─ build_xp.ps1      ← ОДНА команда: проверить синтаксис + пересобрать XP + копия базы
│   ├─ пересобрать-XP.bat ← то же самое двойным щелчком
│   ├─ watch-history.ps1 ← автоистория: сам обновляет архив при правках
│   ├─ история-включить.bat / история-выключить.bat / история-состояние.bat
│   ├─ история-обновить-сейчас.bat / история-автозапуск.bat
│   ├─ dxf_audit.py      ← проверка выгруженного DXF: миллиметры и реальная хорда
│   ├─ package.json      ← зависимости сборщика (Babel)
│   └─ node_modules\     ← уже установлено, интернет для сборки не нужен
│
└─ история\              ← журнал изменений, снимки, переписка, авто-сводки (см. ниже)
```

## Как запустить программу

**Основная версия:** двойной щелчок по `программа\index.html`.
Открывается в браузере. Если браузер по умолчанию — старый (Internet Explorer),
щёлкните правой кнопкой → «Открыть с помощью» → Chrome / Edge / Firefox.

**Windows XP:** сначала установить `программа\XP\Firefox-52.9.0esr-Setup.exe`,
потом открыть `программа\XP\AirfoilStudio-XP.html`. Подробности — в
`программа\XP\Как запустить на Windows XP.txt`.

После любого обновления файла программы браузер может показать старую версию
из кэша — тогда **Ctrl+F5**.

## Как продолжить разработку

1. **Правки вносим в файл программы, который открываем в браузере** — обычно это
   `AirfoilStudio\index.html` (рядом с папкой `Разработка`). Из него «часовой»
   сам обновляет копию в `программа\` и пересобирает XP-версию.
   Если работаете в распакованном архиве — правьте `программа\index.html`,
   слежение это тоже понимает.
2. **Проверка + пересборка XP** — обычно не требуется (слежение делает это само),
   но вручную можно двойным щелчком по `инструменты\пересобрать-XP.bat`, либо
   в консоли:

   ```
   powershell -ExecutionPolicy Bypass -File инструменты\build_xp.ps1
   ```

   Скрипт: извлекает скрипт → проверяет синтаксис (`node --check`) → собирает
   `программа\XP\AirfoilStudio-XP.html` → обновляет запасную копию `airfoil-base.js`.
3. **Проверяем в браузере** — открыть `index.html`, пройтись по вкладкам,
   посмотреть консоль (F12 → Console: ошибок быть не должно).
4. Ничего вручную сохранять не нужно — историю ведёт «часовой» (см. следующий
   раздел). Он сам сделает снимок и запись в журнале.

Требования к машине разработчика:
* браузер Chrome/Edge (или Firefox) — чтобы смотреть результат;
* Node.js 18+ — только для сборки XP-версии;
* Python 3 — только для вспомогательных скриптов (не обязателен).

## История обновляется сама

В `инструменты\` работает маленький «часовой» — `watch-history.ps1`. Он следит
за папкой программы и через 20 секунд после последней правки сам:

* копирует изменённые файлы в `программа\`;
* **пересобирает XP-версию** (и в архив, и в рабочую папку `XP\`, если проверка
  синтаксиса прошла; при ошибке старый файл остаётся целым);
* делает снимок программы в `история\снимки\` (хранятся последние 40);
* дописывает запись в `история\ЖУРНАЛ-ИЗМЕНЕНИЙ.md` — дата, файл, размер,
  сколько строк добавилось;
* не чаще раза в 30 минут обновляет `AirfoilStudio-Разработка.zip` для переноса;
* обновляет `история\СОСТОЯНИЕ.txt` (даты, размеры, SHA256 — по ним всегда видно,
  что архив совпадает с программой).

Слежение уже включено и прописано в автозапуск Windows, то есть после
перезагрузки компьютера оно поднимется само и ничего делать не нужно.

Управление — двойным щелчком в `инструменты\`:

| Файл | Что делает |
|---|---|
| `история-состояние.bat` | работает ли слежение, когда была последняя синхронизация |
| `история-обновить-сейчас.bat` | обновить архив прямо сейчас (не ждать 20 секунд) |
| `история-выключить.bat` | остановить слежение |
| `история-включить.bat` | запустить снова |
| `история-автозапуск.bat` | вернуть автозапуск (если убирали) |

Что важно при переносе:

* При переносе на другой компьютер **автозапуск надо включить заново**
  (`история-автозапуск.bat`) — ярлык в автозагрузке указывает на старый путь.
* Слежение смотрит на папку, где лежит `index.html`. Если распаковали архив
  отдельно и работаете прямо в `программа\`, слежение всё равно работает —
  просто снимки и журнал ведутся по этой же папке.
* Если слежение не запущено, ничего не ломается: историю всегда можно догнать
  командой `история-обновить-сейчас.bat`.

## Правила проекта (их легко случайно нарушить)

Это не прихоти, а договорённости с заказчиком — проверены на практике:

1. **Один файл.** Программа должна оставаться автономным `index.html`
   без внешних библиотек, без сборки и без интернета. Никаких CDN, npm-модулей
   в рантайме, нескольких js-файлов.
2. **Сохранение профиля — только в нижней полосе редактора** (`.savebar`).
   Дублирующих кнопок «сохранить» быть не должно. Поля «хорда» в этой полосе
   тоже быть не должно — хорда задаётся в редакторе и живёт в записи профиля.
3. **Слово «носок» в программе не употребляется** — только «передняя кромка» / «ПК».
4. **Хорда — только в редакторе.** В «Пенорезке» поля хорды нет; там берётся
   `p.chord` из записи профиля.
5. **DXF для SolidWorks — в миллиметрах и в реальную величину** (`$INSUNITS 4`,
   `$MEASUREMENT 1`, координаты умножаются на хорду).
6. **Сетка** в «Профилях», «Редакторе» и «Торцах 2D» — шаг 10 мм, цифры зелёные, 12 px.
7. **Станок:** `invLx`/`invRx` всегда включены, rapid 300 мм/мин.
   **Пенорезка:** отъезд назад 0, подача 150 мм/мин.
8. **База профилей живёт в файле `airfoil-base.js` рядом с программой** и у основной,
   и у XP-версии — одна база на обе программы (подробно в `БАЗА_ПРОФИЛЕЙ.md`).
9. **XP-версия не ломает основную.** Любая правка обязана работать в современном
   браузере; сборка под Firefox 52 — это отдельный производный файл.
10. Интерфейс — по-русски, подписи короткие и «человеческие», без технического жаргона.
