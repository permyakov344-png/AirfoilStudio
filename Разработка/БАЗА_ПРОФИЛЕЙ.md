# База профилей: где живёт, как переносится

Самая больная тема проекта: профили, сохранённые на одном компьютере, не появлялись
на другом. Ниже — как это устроено сейчас и что делать в каждом случае.

---

## Коротко

| Где | Что лежит |
|---|---|
| Браузер (`localStorage`) | рабочая база профилей этого компьютера и этого браузера |
| Файл `airfoil-base.js` рядом с программой | «переносная» база: копируется вместе с программой |
| `XP\airfoil-base.js` | запасная копия на случай, если скопировали только папку `XP` |

**Правило:** файл-база **только добавляет** профили. Ничего не удаляет
и не перезаписывает — это осознанное решение.

---

## Формат файла

Обычный текстовый `.js`, который подключается как скрипт:

```js
/* База профилей Airfoil Studio. Файл создаётся и обновляется самой программой:
   копируй его вместе с программой — на новом компе профили подхватятся сами. */
window.AFOIL_FILE_BASE = [
  { "name": "Мой профиль", "pts": [[0,0],[0.01,0.02], …], "src": "edit", "chord": 250 },
  …
];
```

* В файл попадают **только собственные** профили (`src !== "uiuc"`): библиотечные
  (UIUC/NACA) встроены в программу и восстанавливаются сами.
* Файл — это исполняемый JavaScript, поэтому его содержимое должно быть ровно
  таким, как выше. Ничего своего в него дописывать не надо.

## Откуда программа берёт базу при запуске

### Основная версия (`index.html`)

```html
<script src="./airfoil-base.js"></script>   ← в <head>, до основного скрипта
```

Файл выполняется до старта программы. Дальше `init()`:

1. поднимает локальную базу из `localStorage`;
2. `mergeFileBase()` — добавляет из файла профили, **имён которых локально нет**;
3. если что-то добавилось — сохраняет и показывает уведомление
   «Из файла-базы добавлено профилей: N»;
4. `setBaseInfo()` пишет под кнопкой «База — в файл» состояние файла.

Битые записи (нет `pts`, меньше 4 точек) и совпадающие имена пропускаются.
Имя может быть подправлено (`uniqueProfileName`), если совпало с занятым.

### XP-версия (`XP\AirfoilStudio-XP.html`)

Файл лежит в подпапке, поэтому порядок загрузки другой:

```
1. пробуем  ../airfoil-base.js   (общий файл в корне программы)
2. если не нашёлся — ./airfoil-base.js  (запасная копия рядом с XP-файлом)
3. когда файл загрузился — программа вызывает window.fileBaseLateLoad():
   повторное слияние + обновление списка профилей и подписи
```

Загрузка асинхронная (обычный `<script>` с `onload`/`onerror`) — так надёжнее,
чем `document.write` (на нём был баг с перетиранием общего файла пустой копией).
На `http(s)` к адресу добавляется `?t=…` — обход кэша; на `file://` не нужно,
там файл читается с диска заново.

**Итог:** скопировали папку программы целиком — обе версии видят **один и тот же**
файл `airfoil-base.js` в корне. Скопировали только папку `XP` — работает
запасная копия из этой папки.

## Как записать базу в файл

Кнопка **«База — в файл»** на вкладке «Профили» (`#pBase`).

### Chrome / Edge (основная версия)

1. Первый раз: кнопка открывает диалог сохранения — выберите `airfoil-base.js`
   в папке программы (тот, который уже есть, — его и перезапишет).
2. В диалоге разрешений выберите «Разрешать при каждом посещении» → «Сохранить».
3. Дальше — **ни одного щелчка**: при любом изменении базы программа через
   0,7 с сама перезаписывает файл. Ссылка на файл хранится в IndexedDB
   (`airfoilStudio` → `kv` → `baseHandle`).
4. После перезапуска программа спрашивает право один раз — при первом клике
   по окну (кнопки/клавиши), сама, без диалогов «куда сохранять».

Если файл переименовали или удалили — автозапись просто перестаёт работать,
база остаётся в браузере; кнопка снова предложит выбрать файл.

### Firefox и XP

File System Access API там нет, поэтому кнопка **скачивает** `airfoil-base.js`
в «Загрузки». Его надо переложить в **корень папки программы** (рядом с
`index.html`) — тогда его видят обе версии. Так и написано в XP-инструкции.

> На `file://` (двойной щелчок по `index.html`) Chrome/Edge могут не показывать
> диалог выбора файла: это особенность режима `file://`. В таком случае файл
> тоже скачивается — переложите его вручную.

## Как перенести базу на другой компьютер

1. На рабочем компьютере — «База — в файл» (или дождаться автозаписи).
2. Скопировать **папку программы целиком** на флешку: там уже лежит актуальный
   `airfoil-base.js`.
3. На другом компьютере открыть программу — профили из файла добавятся сами.
4. Если на новом компьютере программа уже стояла и там своя база — файл-база
   **дольёт** недостающие профили, а существующие не тронет.

Обратный перенос (с XP-машины на основную) — так же: «База — в файл» на XP,
скачанный файл — в корень папки программы, дальше обычное копирование.

## Если что-то не так

| Симптом | Причина | Что делать |
|---|---|---|
| «в файле-базе 0 профилей», профили не добавляются | рядом лежит пустой/старый `airfoil-base.js` | нажать «База — в файл» и выбрать правильный файл |
| На другом компьютере профилей нет | скопировали только `index.html`, без `airfoil-base.js`; или файл остался в «Загрузках» | копировать папку целиком; проверить, что файл лежит рядом с `index.html` |
| После обновления файла программа показывает старое | кэш браузера (чаще на локальном сервере) | Ctrl+F5; в XP-версии — на `http` кэш обходится сам |
| Появились профили-дубли с похожими именами | имена отличаются регистром/пробелами/приписками | программа сравнивает имена без учёта регистра; лишний дубль удаляется вручную |
| На XP файл не обновился сам | Firefox 52 не умеет писать в файл | «База — в файл» → переложить из «Загрузок» в корень программы |
| «Не хватает места в localStorage» | база очень большая | почистить лишние профили; файл-база это не лечит (это ограничение браузера) |

## Резервная копия

* `airfoil-base.js` — сам по себе резервная копия базы (плоский текст, легко
  скопировать/переслать).
* Дополнительно: «Выгрузить проект» на вкладке «Профили» — пакет файлов.
* Перед экспериментами с базой достаточно сделать копию `airfoil-base.js`
  с датой в имени — файл читаемый и восстанавливается вручную.
