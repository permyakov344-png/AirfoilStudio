             КАК ЗАПУСТИТЬ AIRFOIL STUDIO НА WINDOWS XP
             =========================================

ЧТО У ВАС В ПАПКЕ XP:
--------------------
1) AirfoilStudio-XP.html          — сама программа (версия для Windows XP)
2) Firefox-52.9.0esr-Setup.exe    — браузер Mozilla Firefox для Windows XP
3) Этот файл-инструкция

ПОЧЕМУ БЫЛА «ОШИБКА DLL»:
------------------------
Современные программы и свежие браузеры (Chrome, Edge, новый Firefox) на Windows XP
уже не работают: им нужны системные библиотеки и функции, которых в XP просто нет.
Поэтому Windows и ругается на какую-то DLL. Лечится это не «допиливанием» XP,
а правильным браузером: последний Firefox, который официально поддерживает XP, —
это Firefox 52. Наш XP-файл программы специально подготовлен под него.

ПОРЯДОК ДЕЙСТВИЙ:
----------------
1. Скопируйте всю папку XP на компьютер с Windows XP (флешкой).

2. Запустите Firefox-52.9.0esr-Setup.exe и установите браузер
   Можно оставить все галочки как есть («Обычная установка»).

3. Откройте AirfoilStudio-XP.html двойным щелчком.
   Если Firefox не сделали браузером по умолчанию — щёлкните по файлу
   правой кнопкой мыши и выберите «Открыть с помощью... → Mozilla Firefox».

4. Всё. Программа запустится: вкладки «Профили», «Редактор», «Пенорезка»,
   «Станок», «Справка» — тот же вид, что и на новом компьютере.

ВАЖНО:
-----
• НЕ открывайте файл через Internet Explorer (синяя буква «e») — на XP из него
  программа работать не будет, потому что IE там слишком старый.
• Настройки программы хранятся в самом браузере. Если копировать программу
  между компьютерами, база профилей не переносится вместе с файлом —
  для переноса базы используйте кнопку «Проект» (сохранить/загрузить .json).
• Экспорт DXF/STEP/.dat/PDF/.tap в XP-версии работает так же, как в полной.

КАК ПЕРЕНОСИТЬ БАЗУ ПРОФИЛЕЙ МЕЖДУ КОМПЬЮТЕРАМИ:
-----------------------------------------------
База профилей у обеих программ ОДНА И ТА ЖЕ: это файл airfoil-base.js
в корне папки программы (рядом с index.html). Копия в папке XP — только
запасная, включается, если копировали одну лишь папку XP.

Во вкладке «Профили» одной и второй программы есть кнопка «База — в файл»:

1. На компе, где вы работали: откройте вкладку «Профили» и нажмите
   «База — в файл». Программа предложит выбрать файл — укажите
   airfoil-base.js в корне программы (рядом с index.html).
   В Chrome/Edge право «Разрешать при каждом посещении» — и дальше
   файл обновляется сам при каждой правке базы.
   В Firefox на XP диалг не откроется: файл скачается в «Загрузки» —
   переложите его в КОРЕНЬ программы (рядом с index.html), там его
   видят обе версии.

2. Скопируйте папку программы на флешку ЦЕЛИКОМ — она уже содержит
   и airfoil-base.js, так больше ничего переносить не надо.

3. На другом компе: открываете программу (любую из двух, но на XP —
   AirfoilStudio-XP.html в папке XP) — профили из файла-базы добавятся
   сами, при каждом запуске.

Важно: файл-база добавляет только те профили, которых на этом компе
ещё нет — ничего не стирает и не портит.

ЕСЛИ ПРИ ЗАПУСКЕ ЧЕГО-ТО ОПЯТЬ ПИШЕТ ПРО DLL:
-------------------------------------------
Обычно помогает установка пакета Microsoft Visual C++ 2010 (x86).
Если у вас есть интернет на этом компьютере — пакет ищется по названию:
«Microsoft Visual C++ 2010 Service Pack 1 Redistributable x86»
(страница Microsoft, центр загрузок). После его установки снова запустите
Firefox-52.9.0esr-Setup.exe.

ПРО СОВРЕМЕННЫЕ КОМПЬЮТЕРЫ:
--------------------------
Полная версия программы — файл index.html в основной папке AirfoilStudio.
Её не трогаем, она для новых Windows и там уже работает.
XP-версия — копия той же программы, собранная под старый браузер.
Если полная версия будет обновляться, XP-версию тоже можно будет
обновить — просто попросите «собери заново XP-версию».
